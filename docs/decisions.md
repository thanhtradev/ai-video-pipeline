| D-037 | Redis on LXC 112 is shared with another application (BullMQ, db 0), so **no port firewall**; the pipeline is isolated by ACL users limited to `q:*`/`nonce:*` and uses db 1 (user, rollout 2026-10-24; R-05) |
| D-038 | Postgres on LXC 102 is shared with other applications, so access to `aivideo` is limited by a **per-database `pg_hba.conf` allow-list ending in `reject`**, placed above the LAN rule; no port firewall (user, rollout 2026-10-24; R-05) |
| D-039 | The Mac mini worker runs from the development checkout `~/remote-dev/AIVIdeo/ai-video-pipeline`, not a separate deploy clone; it is restarted only when that checkout is on an up-to-date `main` (user, 2026-10-24) |
| D-040 | TTS provider: **ITERA TTS** (`itera102.space`), a white-label reseller platform (`api.genmax.io`) running ElevenLabs models (default `eleven_v3`, Vietnamese); credit-based, API key. API details, timestamps, pricing and license terms still to confirm (U-20) (user, 2026-10-25; was Q-003) |
| D-041 | First video format and Remotion template: **typography explainer** (user, 2026-10-25) |
| D-042 | Claude Code runs **headless (`claude -p`)** in the worker for text steps; the user confirms the Max plan terms allow it (user, 2026-10-25; Q-004) |
| D-043 | ITERA narration uses **ElevenLabs `eleven_v3`** (`provider: elevenlabs`, `language_code: vi`; 1 credit per character, at most 5000 characters per request), **one request per scene**: scene timing comes from each clip's measured length, so no alignment step (user, 2026-10-25; was Q-003). First chosen as `eleven_multilingual_v2`, which `GET /v1/models` lists without Vietnamese; changed to `eleven_v3` by the user at the 2b rollout (2026-10-25, migration `20261026000200`). The voice is a registry setting chosen at rollout (`ops/phase-2b.md`) |
| D-044 | ITERA prices and costs are kept in **ITERA credits**, stored with the pseudo currency `CRD` (`provider_price.unit = per_char`); the money price per credit is converted only for reports (U-20, Q-002) |
| D-045 | The cost guard is a **SQL function the worker calls before every paid request** (`cost_guard`), not an n8n sub-workflow (WF-04): the worker is where each paid call happens, and per-scene calls must each be checked. Budget = the TTS estimate approved with A1 (D-023); over budget or no price → NEEDS_DECISION; provider off, quota, key, voice or credit problems → BLOCKED until fixed |
| D-046 | The worker's Claude Code CLI authenticates with a **long-lived token from `claude setup-token`** (Keychain item `aivideo-claude-oauth-token` → `CLAUDE_CODE_OAUTH_TOKEN` in the CLI's environment only), not the interactive login: refreshing that login needs the login Keychain, which is locked when nobody is logged in at the console (2a rollout, 2026-10-25: `OAuth session expired and could not be refreshed`). A CLI login failure blocks the job (BLOCKED, resumes later) instead of using up its attempts |
| D-035 | The project uses **PostgreSQL only**; MariaDB on LXC 102 is not part of the pipeline (uninstalling it is a separate, user-approved server change) |
